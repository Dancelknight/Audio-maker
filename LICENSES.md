# Third-party components

This project uses third-party components loaded at runtime.

## Piper voice: de_DE-thorsten

The Thorsten German Piper voice is distributed by the Piper voice repository.
Its model card states that the underlying Thorsten dataset is CC0.

Model source:
https://huggingface.co/rhasspy/piper-voices

## ONNX Runtime Web

Microsoft ONNX Runtime Web.
License: MIT.
https://github.com/microsoft/onnxruntime

## Phonemizer.js

Phonemizer.js by Xenova.
License: Apache-2.0.
https://github.com/xenova/phonemizer.js

## lamejs

lamejs.
License: LGPL-3.0.
https://github.com/zhuker/lamejs

The application code in this folder was created for this project and does not bundle the source code of the third-party libraries above; they are loaded from their published CDN distributions.
